# SAP-1 Computer Architecture Simulator

An interactive SAP-1 (Simple-As-Possible-1) Computer Architecture Simulator developed using JavaScript, HTML, and CSS. This project demonstrates the fundamental concepts of computer organization, CPU operations, memory management, and instruction execution.

##  Project Overview

The SAP-1 simulator is designed to demonstrate how a basic computer processor works. It simulates the internal operations of a simple CPU, allowing users to understand how instructions are fetched, decoded, and executed.

The project provides an interactive environment for exploring the basic components and operations of the SAP-1 architecture.

##  Features

- Interactive SAP-1 computer simulation
- CPU instruction execution
- Memory operations
- Register operations
- Fetch, Decode, and Execute cycle
- JavaScript-based simulation logic
- User-friendly interface
- Automated tests using Node.js

##  Technologies Used

- HTML5
- CSS3

##  Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Tetxie143/SAP-1-Computer-Architecture.git
```

2. Navigate to the project directory:

```bash
cd SAP-1-Computer-Architecture
```

3. Open the `index.html` file in your web browser.

##  Running Tests

Make sure Node.js is installed on your computer.

Run the following command:

```bash
node --test
```
